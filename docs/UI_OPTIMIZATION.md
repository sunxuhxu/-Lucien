# 许墨 · Lucien UI 深度优化交付说明

## 设计定位

本轮将界面从“高饱和紫色功能集合”升级为“雾紫 × 墨蓝 × 玫瑰金”的轻奢角色陪伴体验。核心气质是克制、亲密、理性、带少量神秘感；视觉上保留许墨品牌已有的紫色识别，同时降低霓虹感和无意义发光，改用更细腻的材质、留白与字体层级表达高级感。

设计关键词：`Cinematic`、`Editorial`、`Quiet Luxury`、`Intimate AI Companion`、`Soft Glass`。

## 优化前后对比

| 维度 | 优化前 | 优化后 |
| --- | --- | --- |
| 色彩 | 紫色与粉色使用范围过大，强调层级相近 | 雾紫作为品牌色，墨蓝承载正文，玫瑰色仅用于高价值强调；成功、危险均改为语义色 |
| 字体 | 手写体、宋体、黑体混用，正文局部尺寸偏大 | 标题采用宋体气质，正文采用清晰黑体，许墨回复保留文楷作为角色声线 |
| 层级 | 组件阴影与渐变强度接近，页面视觉中心分散 | 统一三档阴影、五档圆角与克制的玻璃材质；主操作与次级操作明确分层 |
| 布局 | 顶部操作区纵向堆叠风险高，移动端控件密集 | 桌面端工具条改为可换行横向布局；移动端只保留“通话 / 引导”核心入口 |
| 交互 | 仍有依赖 hover 的次级反馈，按钮图标风格不统一 | 关键工具栏替换为同一线性 SVG；hover、pressed、disabled、focus、loading 状态完整 |
| 动效 | 多处持续漂浮、发光与放大，注意力竞争 | 统一 160/240ms 节奏，仅保留因果明确的位移与状态反馈；完整支持 reduced-motion |
| 无障碍 | 部分应用图标缺少可读名称，缺少跳转主内容入口 | 自动补全 aria-label、图片尺寸与 loading 语义；增加 skip link、live region 和清晰焦点环 |
| 响应式 | 小屏顶部区域与工具按钮容易拥挤 | 760px / 390px 两级内容优先策略，44px 触控尺寸，safe-area 与横竖屏兼容 |

## 设计令牌

### 色彩

- `--ui-ink-950: #17142B`：主文字，白底对比度远高于 WCAG AA。
- `--ui-violet: #7657B7`：品牌主色，用于选中、焦点与主操作。
- `--ui-rose: #BF668D`：情感强调色，仅用于高价值状态与渐变尾端。
- `--ui-gold: #B58B55`：纪念、成就等稀有信息。
- `--ui-canvas: #F7F5FB`：全局背景。
- `--ui-surface: rgba(255,255,255,.92)`：浮层与高阶表面。
- `--ui-success: #277C65` / `--ui-danger: #B94B5B`：语义状态色。

### 排版

- 展示 / 标题：`Noto Serif SC`，600。
- 正文 / 控件：`Noto Sans SC`，400–600。
- 角色回复：`LXGW WenKai`，保留人物叙事感。
- 正文行高：1.5–1.75；角色回复：1.85。
- 数字时间使用 `font-variant-numeric: tabular-nums`，避免跳动。

### 间距、圆角和阴影

- 间距遵循 4 / 8 基础栅格，常用间距为 8、12、16、24、32。
- 圆角：8 / 12 / 18 / 26 / 36px，按控件、卡片、面板逐级提升。
- 阴影：`--ui-shadow-1/2/3`，分别用于卡片、浮层、模态。
- 最大正文宽度控制在约 60–75 个中文字符的视觉等价范围。

### 动效

- 快速反馈：160ms；标准过渡：240ms。
- 进入与 hover 使用 `cubic-bezier(.16,1,.3,1)`。
- 只动画 `transform` 与 `opacity`，避免布局抖动。
- `prefers-reduced-motion: reduce` 下关闭持续动画与平滑滚动。

## 组件规范

### 主按钮

- 使用品牌渐变，仅允许每个屏幕一个主按钮。
- 高度不低于 44px；pressed 状态缩放不超过 0.97。
- loading 时必须设置 `disabled`，增强脚本会同步 `aria-busy=true`。

### 次级按钮

- 使用白色半透明底、细描边和墨紫文字。
- hover 只提升 1px，不改变布局尺寸。
- 图标统一为 1.8px 线性 SVG。

### 卡片

- 默认使用纯色或高不透明度表面，不依赖透明模糊制造层级。
- 仅顶层浮层和导航允许 blur，普通内容卡片使用实体背景以保证性能和可读性。

### 聊天气泡

- 许墨：白色表面 + 文楷，左下角 6px。
- 用户：低饱和雾紫表面，右下角 6px。
- 元信息使用等宽数字，颜色对比不低于 3:1。

### 手机桌面

- 应用图标保持现有品牌资源，统一投影、圆角与 pressed 反馈。
- 分类标签为次级导航，选中态使用品牌渐变。
- Dock 与 Widget 使用同一层级玻璃材质，减少多套材质混杂。

## 验收标准

- 375 / 768 / 1024 / 1440px 无横向滚动。
- 移动端核心触控目标不小于 44×44px。
- 键盘可见焦点完整，Tab 顺序遵循 DOM 与视觉顺序。
- 正文对比度达到 WCAG 2.2 AA；辅助文字达到 3:1。
- reduced-motion 下无持续漂浮或闪烁。
- 固定导航、底部输入区和应用内容均避开 safe-area。
- 浏览器控制台无由本次增强资源引入的错误。
